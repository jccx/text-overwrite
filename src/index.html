Text Overwrite

Release to open this image

  1. Select the text to changeDrag a box around it on the image, covering just the text and its background. One style at a time.
  2. Check the original textChinese, English, or mixed text all work. It is used to match the font, weight, size, spacing and colour.
  3. Type the new text, then ApplyThe old text is erased and the background filled back in. With the same number of characters, the new text lands where the old was; with a different count, the original indent, spacing, gaps and line spacing are kept.

Pinch to zoom and move the image; on a computer, scroll to zoom and hold Space to drag. Images are processed on your device. When the original text is opened in Claude, Claude reads it (only the small boxed area is sent, and you are asked first); on the shared web page, the built-in reader reads it on your device: common Hei, Song and English print faces can be read, while handwriting and decorative type may be read wrong, so type those in by hand.

Privacy and terms

Images and PDFs never leave your device

Opening, recognising, editing and saving all happen in your browser. This app has no backend server: it does not upload, store or collect your images, PDFs or text, and it has no analytics or advertising code.

The app only requests its program and font files from this site. The site is hosted on GitHub Pages, and GitHub keeps access logs like any other website (for example, IP addresses); those logs contain none of your images or files.

Offline font packs and settings are stored in this browser; you can delete them under “Set up offline use”, and clearing this site’s data removes them too.

Source code is public

All source code is open source under GNU AGPL v3; you can read it to check the claims above: github.com/jccx/text-overwrite
